An entry for the [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) bounty on [make.fun](https://make.fun): a program that explains a puddle to a 10-year-old in two lines — line 1 builds the explanation on an analogy, line 2 says what that analogy maps and what it leaves out — written to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program is deterministic: it writes the same UTF-8 text (281 characters, no trailing newline) on every run, uses no network, and reads no input.
